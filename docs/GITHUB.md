# GitHub收录范围

本仓库保存源码与阶段展示成果，继续保持私有。公开与网站部署分别决定。

保留：前后端源码、配置模板、章节与校核资料、测试代码和用例、启动／备份脚本、必要说明、用户已确认的5张截图。

默认排除：`.env`和真实密钥、`data/`、`backups/`、数据库、匿名身份、个人会话、原始QA对话、批量截图和日志。新运行的验收工具仍可在本机生成`docs/qa/`，该目录默认忽略；展示图集中在[screenshots](screenshots/README.md)。

2026-11-11按用户要求清理早期无用材料：移除本机原始QA、重复归档和旧审阅台，并将主分支整理为初始忽略规则加当前完整源码。含批量QA的中间提交不再属于主分支历史；源码、史料、测试用例、现有游客数据与必要数据备份保留。

GitHub可能暂存不可达旧对象或缓存，重写分支不能保证旧SHA链接立即失效；本次没有删除仓库、改变可见性或声称完成平台级彻底擦除。

检查项见[公开前清单](PUBLIC-RELEASE-CHECKLIST.md)。自动扫描不等于隐私和许可审查全部完成。
